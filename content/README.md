# Content System

This directory is the future home of educational material independent from simulation logic.

Planned domains: `blocks/`, `anatomy/`, `curriculum/`, `cases/`, `quizzes/`, `debriefing/`, `instructor/`.

Content can be Markdown/MDX/JSON/YAML depending on use. It must be reviewable/versioned and may reference stable Data or Media IDs, but it cannot directly mutate simulation state or contain hidden simulation formulas.
