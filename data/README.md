# Data System

This directory is the future home of versioned, schema-validated machine-readable platform definitions.

Planned domains: `anatomy/`, `blocks/`, `probes/`, `needles/`, `presets/`, `scenarios/`.

Phase 0 intentionally does not move existing canonical core datasets here. Migration occurs only with parity/regression tests and explicit DATA versioning/freezes.

Data may parameterize canonical cores through explicit loaders/adapters; it does not replace executable core logic.
