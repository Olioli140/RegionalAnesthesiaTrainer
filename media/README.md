# Media Production System

This directory owns media production metadata and, in later phases, source/master/processed/production media packs.

Current runtime WebP files remain under the app `public/assets` path during Phase 0 to preserve deployment behavior. Their new registry entries live under `media/manifests/`.

Planned structure:

- `source/`
- `masters/`
- `processed/`
- `production/`
- `metadata/`
- `manifests/`

Media is presentation/reference material and never Simulation Truth.
